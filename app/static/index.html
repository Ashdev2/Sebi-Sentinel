System & data settings

Model

Normally Sentinel retrains automatically after a newly retrieved stock adds substantial history. Use this only when you want to force a full retrain.

Verified regulatory cases

Import only case records you have verified from an authoritative regulator source. These labels can enable the known-case classifier.

Manual CSV fallback

Not required for normal stock searches. Keep this only for older history outside the NSE MCP window or offline work.
